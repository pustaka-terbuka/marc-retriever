📖 Universal URL Query String API

Retrieve MARC records for any supported Malaysian public library using the clean path format /ppl?isbn=<ISBN>:

GET https://pustaka-terbuka.github.io/marc-retriever/pnm?isbn=9789831665541
GET https://pustaka-terbuka.github.io/marc-retriever/ppas?isbn=9678915006

Append &raw=true for raw unstyled JSON output (ideal for machine ingestion, curl, and Python requests):

GET https://pustaka-terbuka.github.io/marc-retriever/pnm?isbn=9789831665541&raw=true
