🇲🇾 Perpustakaan Negara Malaysia (PNM)

marc-pnm

Query PNM's Online Public Access Catalog by ISBN and extract complete MARC21 records in JSON format.

Try examples: 9789831665541 (Mudahnya Sifir) 0755438140 (Sleepytime Stories) 9789674880000 

  


  

    
📖 Query String API Usage

    
You can query this web app directly via URL query parameter ?isbn=<ISBN> to return the complete MARC data:

    
    

      

        GET
        
          https://pustaka-terbuka.github.io/marc-pnm/?isbn=9789831665541
        
      

    


    
Add &raw=true or &raw=1 to receive pure, unstyled JSON in the browser:

    

      

        GET
        
          https://pustaka-terbuka.github.io/marc-pnm/?isbn=9789831665541&raw=true
