📖 Direct Query String Usage

    
Retrieve MARC JSON records directly from u-Pustaka using the /u-pustaka?isbn=<ISBN> route:

    
    

      

        GET
        
          https://pustaka-terbuka.github.io/marc-retriever/u-pustaka?isbn=9789831665541
        
      

    


    
Append &raw=true for direct unstyled JSON output:

    

      

        GET
        
          https://pustaka-terbuka.github.io/marc-retriever/u-pustaka?isbn=9789831665541&raw=true
